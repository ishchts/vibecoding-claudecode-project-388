# Извлечение цены товара

## Входные данные

Один URL страницы конкретного товара. Проверяй только этот товар и выбранный на странице вариант. Если передано несколько URL или ссылка на каталог, попроси один URL конкретного товара.

## Порядок извлечения

1. Открой URL и получи содержимое страницы с помощью доступного инструмента чтения веб-страниц или HTTP-клиента. Сохраняй проверку TLS. Убедись, что получена карточка нужного товара, а не страница ошибки, авторизации или CAPTCHA.
2. Если цены загружаются динамически, используй доступный браузер, дождись появления блока покупки и прочитай отрисованную страницу. Не обходи ограничения доступа и не считай HTML страницы блокировки данными товара. Если браузер недоступен или доступ запрещён, сообщи об этом как о причине неудачи.
3. Найди обычную цену, цену со скидкой и сведения о рассрочке в блоке покупки этого товара. При необходимости проверь структурированные данные Product/Offer и встроенные данные страницы; сопоставь их с выбранным вариантом и видимыми условиями предложения. Не используй цены рекомендаций, других продавцов, других вариантов, доставки, кешбэка или ежемесячных платежей. Не подменяй текущую цену данными поисковой выдачи.
4. Нормализуй найденные значения в числа в рублях: убери символ валюты, подписи, обычные и неразрывные пробелы; десятичную запятую преобразуй в точку. Например, `1 200 ₽` → `1200`, `950,50 руб.` → `950.5`. Не конвертируй другую валюту без подтверждённой цены в рублях.
5. Проверь результат по контракту ниже и верни его. Не вычисляй отсутствующую цену из процента скидки или суммы платежей и не придумывай значения.

## Правила определения полей

- `regular_price`: обычная полная цена товара в рублях. Если показаны старая зачёркнутая и новая цены, обычной считай старую. Если есть единственная явно обозначенная полная цена без скидки, используй её. Если показана только скидочная цена, обычная цена остаётся `null`.
- `sale_price`: минимальная явно указанная полная цена разовой покупки выбранного товара в рублях, включая специальную цену по карте, банку или подписке. Сравнивай только цены этого товара, варианта, количества и предложения; не используй ежемесячные платежи, цену за единицу из другого комплекта или предложения других продавцов. Если скидки или специальной цены нет либо её значение не найдено, верни `null`.
- `has_credit`: `true` только при явном упоминании рассрочки или графика платежей для данного товара. Надпись «Оплатить позже» сама по себе не подтверждает рассрочку. Общая реклама кредита, обычный кредит и отдельный ежемесячный платёж без подтверждённого графика также не достаточны. После успешной загрузки и проверки карточки отсутствие признаков рассрочки означает `false`. Если страницу или необходимые сведения проверить невозможно, используй ответ `extraction_failed`, описанный ниже.

## Контракт ответа

При успешном извлечении верни только JSON-объект без Markdown, пояснений и дополнительных полей:

```json
{
  "regular_price": 1200,
  "sale_price": 950,
  "has_credit": true
}
```

Обе цены должны быть положительными конечными числами без пробелов, валюты и текста либо `null`. `has_credit` должен быть булевым значением. Если обе цены найдены, скидочная должна быть меньше обычной; при противоречии перепроверь источник и оставь неподтверждённое поле `null`. Отсутствие скидки (`sale_price: null`) само по себе не является ошибкой.

Если карточка доступна и сведения о рассрочке проверены, но цену извлечь невозможно или цена определена лишь частично, верни объект с `null` у ненайденных цен, затем отдельной короткой строкой сообщи причину. Не включай причину в объект цен.

Если страница недоступна, вместо карточки получена CAPTCHA или блокировка, произошла сетевая/TLS-ошибка, либо не удалось проверить сведения о рассрочке, верни отдельный объект ошибки без полей цен и `has_credit`:

```json
{
  "status": "extraction_failed",
  "reason": "Доступ к странице запрещён; цены и наличие рассрочки проверить не удалось."
}
```

Перед ответом с данными товара проверь наличие ровно трёх ключей, типы значений, валюту, привязку к нужному товару и отсутствие подмены полной цены ежемесячным платежом. Для ответа об ошибке проверь наличие только `status` со значением `extraction_failed` и `reason` с краткой фактической причиной. Не объявляй извлечение успешным по HTTP-статусу или одному лишь открытию страницы.

## Результаты проверки

Результаты проверки четырёх URL сохранены в [references/validation.md](references/validation.md). Они служат примерами применения контракта; при новом запуске получай актуальные данные страницы, не подставляй сохранённые цены.
