# Проверка extract-price

Дата проверки: 1 октября 2026 года. Страницы проверены Chromium в облачной среде с включённой проверкой TLS и уже установленным сертификатом прокси среды. Это результаты конкретного запуска, а не постоянные цены или гарантии доступности сайтов.

## Ozon — успешная проверка

URL: https://www.ozon.ru/product/kofe-mehmet-efendi-naturalnyy-molotyy-250-g-1897146655/

Карточка выбранного товара загрузилась. В блоке покупки указаны зачёркнутая обычная цена 1900 ₽, цена 1037 ₽ с другими банками и специальная цена 933 ₽. Минимальная цена разовой покупки — 933 ₽. Надпись «Оплатить позже без % до 18 декабря» не подтверждает рассрочку; явного предложения рассрочки или графика платежей в проверенной карточке не найдено.

```json
{
  "regular_price": 1900,
  "sale_price": 933,
  "has_credit": false
}
```
